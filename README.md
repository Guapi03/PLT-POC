# PLT-POC (Lab Equipment Online & AR Viewer)

This project is a Proof of Concept (POC) designed to explore modern, interactive ways of viewing and inspecting laboratory equipment online.

🔗 **Live Demo & AR View:** [https://test.guapi03.workers.dev/](https://test.guapi03.workers.dev/)

---

## 🌟 Key Features

* **Online Equipment Inspection (Web View):** 
  * Allows users to interactively view 3D models of laboratory equipment directly through the browser.
  * Check equipment details, structure, and real-time visual status without needing physical access.

* **Augmented Reality (AR) View:**
  * Supports AR view on compatible mobile devices (e.g., via WebXR / Quick Look / Model Viewer).
  * Place lab equipment in your real-world environment to inspect dimensions, scale, and spatial placement before physical setup.

---

## 🎯 Purpose of POC

The main goal of this Proof of Concept is to evaluate the feasibility and performance of bringing laboratory asset management and educational inspection into interactive 3D and immersive AR space on the web.

---

## 🛠️ Tech Stack

* **Frontend Hosting:** Cloudflare Workers / Pages
* **3D / AR Rendering:** WebXR / 3D Model Viewer Technologies
* **Version Control:** Git & GitHub
